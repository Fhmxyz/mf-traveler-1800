# One Sentence for a Traveler from 1800

One sentence explaining the modern internet to someone arriving from 1800, built only from things they would already know: libraries, post offices, market stalls, and a single road.

Run it with:

```sh
python3 main.py
```

It writes the sentence to `/output/entry.txt`.

Entry for the make.fun bounty "One Sentence for a Traveler from 1800".
